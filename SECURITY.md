# Security policy

Research prototype: do not use real credentials. No supported production release exists.
Do not put credentials, pairing codes, keys or memory dumps into issues or reports.
Report reproducible findings using synthetic inputs, versions and redacted diagnostics.
A private reporting channel must be configured before public release; until then
do not disclose exploitable details in public issues. No contact address is invented.

No clipboard, elevation, security-desktop bypass, telemetry or secret logging is allowed.
Hardware assurance, authenticated device claims, target input and memory cleanup
require independent evidence before enabling sensitive transfer. See THREAT_MODEL.md
and IMPLEMENTATION_STATUS.md under docs for current limitations.
